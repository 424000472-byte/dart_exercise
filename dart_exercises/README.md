## Program Description

The Student Allowance Calculator is a simple Dart console program that calculates a student's remaining daily allowance and estimated weekly allowance. It demonstrates `int`, `double`, `String`, and `bool` variables, arithmetic and comparison operators, and console output using `print()` and string interpolation.

## Requirements

- Dart SDK installed
- Terminal or command prompt

## How to Run

1. Open a terminal in the project folder.
2. Run the program:

   ```bash
   dart run
   ```

3. Check the displayed results.
4. Save the actual terminal output in `output.txt`.
